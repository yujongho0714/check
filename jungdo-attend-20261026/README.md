# 정도 출결 — 폰 2대로 만드는 등원·하원 문자 시스템

용인대 정도 태권도 2관 전용 (혼자 쓰는 용도, 상업용 아님)

- **기기 A (출석 단말기)**: 유심 없는 공기계/태블릿. 아이가 이름 → [등원]/[하원] 터치
- **기기 B (문자 발송 폰)**: 관장님 폰(유심 있음). 신호를 받아 **관장님 폰 요금으로** 학부모님께 문자 자동 발송
- **문자 내용은 관장님이 써둔 문구 그대로** 나가고, **날짜별 안내(전체 공통 + 부별)**를 미리 적어두면 그날 문자에 자동으로 붙습니다.

앱은 **하나**입니다. 같은 APK를 두 기기에 설치하고, 처음 켤 때 "출석 단말기"/"문자 발송 폰" 중 하나를 고르면 됩니다.

## 0. 원래 쓰시던 출결 앱(groupsms.apk) 뜯어본 결과

| 항목 | 원본 앱 (시소모바일 단체문자) | 이 앱 (정도 출결) |
|---|---|---|
| 키오스크 → 폰 전달 | 키오스크 → **회사 서버(PHP)** → **FCM 푸시** → 관장님 폰 | 키오스크 → **Firebase Firestore(실시간 DB)** → 관장님 폰 |
| 문자 발송 | `MyFirebaseMessagingService` 안에서 `SmsManager.sendTextMessage` / 긴 문자는 `sendMultipartTextMessage`, `SMS_SENT`로 결과 확인 | **같은 방식** (`SmsSender.kt`) |
| 폰이 잠들지 않게 | 배터리 최적화 제외 요청, WAKE_LOCK | **같은 방식** + 상단 알림이 떠 있는 '포그라운드 서비스' |
| 비용 | 월 이용료 | **무료** (Firebase 무료 요금제 + 관장님 폰 문자 요금) |

즉, 원본 앱의 핵심 구조(“폰이 문자 서버 역할”)는 그대로 두고, 회사 서버만 Firebase로 바꾼 것입니다.

## 1. 전체 구조

```
 [기기 A: 출석 단말기]                [Firebase Firestore]                 [기기 B: 관장님 폰]
  아이가 "홍길동 → 등원" ──저장──▶  events/  status=PENDING  ──실시간──▶  SmsService(백그라운드)
                                                                           │ ① PENDING→SENDING 찜
  화면에 "등원 완료!"             config/messages (기본 문구)  ◀──읽기────┤ ② 문구 + 그날 안내로 문자 작성
  + "홍길동 등원" 음성             notices/2026-10-27 (날짜별 안내)         │ ③ SmsManager 로 학부모님께 발송
                                                                           ▼
  오늘 기록에 '발송완료' 표시  ◀──  events/  status=SENT/FAILED  ◀──기록── ④ 결과 기록
```

- 와이파이가 잠깐 끊겨도 기기 A가 신호를 보관했다가 연결되면 자동 전송합니다.
- 관장님 폰이 꺼져 있다가 늦게 켜지면, **30분 넘게 지난 신호는 문자를 안 보냅니다** (밤에 "등원했습니다" 문자가 가는 것 방지, 설정에서 변경 가능).
- 10분 안에 같은 아이가 같은 버튼을 또 누르면 "이미 등원했어요, 다시 보낼까요?" 확인창이 뜹니다.

## 2. 문자 내용 설정 (매일 바뀌는 수업 안내)

관장님 폰 → **[문자·안내] 탭** (키오스크 관리자 화면에도 같은 탭이 있습니다)

### ① 기본 문구
등원 문자, 하원 문자를 원하는 대로 쓰세요. 아래 글자는 자동으로 바뀝니다.

| 칸 | 바뀌는 내용 | 예 |
|---|---|---|
| `{이름}` | 아이 이름 | 홍길동 |
| `{시각}` | 버튼 누른 시각 | 오후 3:05 |
| `{구분}` | 등원/하원 | 하원 |
| `{부}` | 원생의 부 | 3부 |
| `{날짜}` | 날짜 | 10월 27일 |
| `{안내}` | 그날 안내 (아래 ②) | 내일은 품새 심사 연습입니다 |

예)
```
[용인대 정도태권도 2관] {이름} 수련생이 {시각}에 수업을 마치고 하원합니다.
{안내}
```

### ② 날짜별 안내
- ◀ ▶ 로 날짜를 고르고, **전체 공통 안내**를 적고 [저장]
- **부별 안내**도 따로 쓸 수 있습니다. (예: 6부만 "시범단 연습 30분 연장") 부별 칸이 비어 있으면 공통 안내가 나갑니다.
- 내일·모레 안내를 **미리** 적어두면 그 날짜에 자동으로 나갑니다.
- 안내가 없는 날은 `{안내}` 줄이 자동으로 빠집니다.

### ③ 미리보기
실제로 나갈 문자와 글자 수, 문자 몇 통으로 나가는지 보여줍니다. (한글 70자 넘으면 여러 통으로 나뉘거나 기종에 따라 장문 1통)

> 문자 문구·안내는 Firebase에 저장되므로 **어느 기기에서 고쳐도 바로 반영**됩니다.

## 3. 준비물

- 기기 A: 안드로이드 8.0 이상 공기계/태블릿 (와이파이)
- 기기 B: 관장님 안드로이드 폰 (유심, 문자 무제한 요금제 권장)
- 구글 계정 (Firebase 용) — 기존 끝말잇기 프로젝트와 **따로 새 프로젝트**를 만드는 걸 권장 (학부모 번호가 들어가니까요)
- 도장 PC (깃허브에 폴더째 올리기용) — 또는 안드로이드 스튜디오

## 4. Firebase 설정 (처음 한 번, 약 10분)

1. https://console.firebase.google.com → **프로젝트 추가** → 이름 예: `jungdo-attend` (애널리틱스는 꺼도 됨)
2. 프로젝트 홈에서 **안드로이드 아이콘(앱 추가)** 클릭
   - Android 패키지 이름: **`com.jungdo.attend`** (정확히 똑같이)
   - 앱 닉네임: 정도 출결 → **앱 등록**
   - **`google-services.json` 다운로드** → 깃허브 빌드면 5장의 Secrets 에 붙여넣기 (저장소에 올리지 않기) / 안드로이드 스튜디오면 `app` 폴더 안에 넣기
   - 나머지 단계(SDK 추가 등)는 이미 코드에 들어있으니 '다음'만 누르면 됩니다.
3. 왼쪽 메뉴 **빌드 → Authentication → 시작하기**
   - 로그인 방법: **이메일/비밀번호** → 사용 설정 → 저장
   - **Users 탭 → 사용자 추가**: 예) `jungdo2@도장메일.com` / 비밀번호 → 이 계정으로 두 기기 모두 로그인합니다.
4. 왼쪽 메뉴 **빌드 → Firestore Database → 데이터베이스 만들기**
   - 위치: **asia-northeast3 (서울)**
   - **프로덕션 모드**로 시작
5. Firestore → **규칙** 탭 → 이 폴더의 `firestore.rules` 내용을 붙여넣고, `dojang@example.com` 을 3번에서 만든 이메일로 바꾼 뒤 **게시**
   - 이렇게 하면 그 계정으로 로그인한 기기만 원생 번호를 읽고 쓸 수 있습니다.

> 무료 요금제(Spark) 한도: 하루 쓰기 2만 건 / 읽기 5만 건. 원생 100명이 하루 2번씩 찍어도 수천 건 수준이라 충분합니다.

## 5. APK(설치 파일) 만들기

### 방법 A — 깃허브 자동 빌드 (무료 · 공개 저장소 OK · 안드로이드 스튜디오 필요 없음)

> **공개 저장소에는 아래 두 파일을 절대 올리지 마세요.** 대신 깃허브 '비밀값(Secrets)'에 넣습니다.
> - `google-services.json` (Firebase 설정)
> - 서명키 (`keep-private-20261026` 폴더 — 프로젝트 폴더 밖에 따로 들어 있음)
>
> 원생 이름·번호는 코드에 없고 Firebase 에만 저장되므로 저장소가 공개여도 보이지 않아요.

1. 도장 PC에서 깃허브 → **New repository** → 이름 예: `attend-app` → **Public** → Create
2. **uploading an existing file** → ZIP을 푼 `jungdo-attend-20261026` 폴더 **안의 내용 전부**(app, gradle, .github, gradlew 등)를 끌어다 놓기 → Commit
   - `.github` 폴더가 안 올라갔다면: **Actions** 탭 → *set up a workflow yourself* → `.github/workflows/build-apk.yml` 내용 붙여넣기 → Commit
3. 저장소 **Settings → Secrets and variables → Actions → New repository secret** 을 두 번:
   | Name | Secret (값) |
   |---|---|
   | `GOOGLE_SERVICES_JSON` | Firebase 에서 받은 `google-services.json` 을 메모장으로 열어 **전체 복사·붙여넣기** |
   | `SIGNING_KEY_BASE64` | `keep-private-20261026/SIGNING_KEY_BASE64.txt` 내용 **전체 복사·붙여넣기** |
4. **Actions** 탭 → Build APK → **Run workflow** (5~8분, 초록 ✔ 되면 완료)
5. 저장소 오른쪽 **Releases → app-debug.apk** 를 폰에서 받아 설치
   - 공개 저장소라 APK 는 누구나 받을 수 있지만, 도장 계정으로 **로그인해야만** 쓸 수 있어요
6. 코드를 고쳐 다시 올리면 새 APK 가 자동으로 만들어지고, 같은 서명키라 **덮어서 설치**하면 설정이 유지돼요

**공개 저장소 보안 한 가지 더 (꼭):** Firebase 콘솔 → Authentication → **설정 → 사용자 작업 → '생성(가입) 사용' 끄기**. 이렇게 하면 관장님이 만든 계정 외에는 아무도 가입할 수 없어요. (`firestore.rules` 에서 도장 이메일만 허용하므로 이중 잠금)

### 방법 B — 안드로이드 스튜디오

1. Android Studio 설치 → **Open** → 이 폴더 선택 → 아래쪽 Gradle Sync 끝날 때까지 대기
2. 메뉴 **Build → Build App Bundle(s)/APK(s) → Build APK(s)**
3. 완료 알림의 **locate** → `app-debug.apk` 를 두 폰에 옮겨 설치 (또는 USB 연결 후 ▶ 실행)

## 6. 기기 B (관장님 폰) 설정

1. 앱 실행 → 4-3에서 만든 계정으로 로그인 → **📱 문자 발송 폰** 선택
2. [상태·기록] 탭의 **준비 상태**를 모두 ✅ 로:
   - 문자 보내기 권한 → 허용
   - 알림 표시 권한 → 허용
   - 배터리 최적화 제외 → 허용
3. **삼성 폰이면 추가로**: 설정 → 배터리 → 백그라운드 사용 제한 → **사용 안 함 앱(절전 예외)** 에 '정도 출결' 추가
4. **[서버 켜기]** → 상단 알림에 "문자 서버 작동 중"이 계속 떠 있으면 정상
5. [설정] 탭 → **테스트 문자 보내기**에 관장님 번호 → 문자 오면 성공
6. [문자·안내] 탭에서 문구 작성
7. 폰을 재부팅해도 서버는 자동으로 다시 켜집니다.

> 권한 허용 버튼이 회색으로 막혀 있으면: 설정 → 애플리케이션 → 정도 출결 → 오른쪽 위 ⋮ → **제한된 설정 허용** 후 다시 시도 (깃허브/직접 설치한 앱에 안드로이드가 거는 보호 장치)

## 7. 기기 A (출석 단말기) 설정

1. 앱 실행 → 같은 계정으로 로그인 → **🧒 출석 단말기** 선택
2. 위의 **"용인대 정도 태권도 2관" 글자를 길게 누르기** → 관리자 비밀번호 **0000** → [설정] 탭에서 꼭 바꾸세요
3. **[일괄 등록]** 탭: 엑셀에서 `이름 | 부 | 연락처1 | 연락처2` 열을 복사해 붙여넣기 → 등록
   - 또는 `홍길동, 3부, 010-1234-5678` 처럼 한 줄에 한 명
4. [출석 화면으로] → 상단 오른쪽에 **● 문자 연결** (초록)이 보이면 관장님 폰과 연결된 것
5. 아이들이 다른 앱으로 못 나가게: 설정 → 보안 → **앱 고정(화면 고정)** 켜기 → 최근 앱 화면에서 정도 출결 아이콘 → **이 앱 고정**
6. 충전기 연결해 두기 (화면이 계속 켜져 있도록 만들어져 있음)

화면 사용법: 부 버튼(1부~6부)과 초성 버튼(ㄱㄴㄷ…)으로 이름을 빨리 찾고, 이름 → **등원**/**하원**. 등원한 아이는 초록, 하원한 아이는 회색으로 표시됩니다.

## 8. 꼭 알아둘 점 / 문제 해결

| 증상 | 원인·해결 |
|---|---|
| 한꺼번에 많이 보낼 때 폰에 "이 앱이 많은 문자를 보내고 있습니다" 창 | 안드로이드 기본 제한(30분에 30건). 창이 뜨면 **항상 허용**에 체크. 안 되면 PC에 폰을 USB로 연결하고 `adb shell settings put global sms_outgoing_check_max_count 1000` |
| 몇백 건 이후 문자가 실패 | 통신사 개인 회선 **하루 발송 한도**가 있을 수 있음 (요금제·통신사마다 다름) → 통신사에 확인 |
| 문자가 늦게 가거나 안 감 | ① 관장님 폰 상단 알림 "문자 서버 작동 중" 있는지 ② 배터리 최적화 제외/삼성 절전 예외 ③ 폰이 와이파이·데이터 연결돼 있는지 |
| 키오스크에 "● 문자폰 꺼짐" | 관장님 폰 서버가 꺼져 있거나 인터넷이 끊김. 키오스크에서 누른 신호는 저장돼 있다가 서버가 켜지면 발송(30분 이내 것만) |
| 실패한 문자 | 관장님 폰 [상태·기록] 또는 키오스크 관리자 [오늘 기록]에서 **재발송** |
| 아이가 다른 아이 이름을 눌렀음 | 문자가 나가기 전(대기)이면 키오스크 관리자 [오늘 기록]에서 **취소** |
| 로그인 실패 | Authentication 에 이메일/비밀번호 사용 설정했는지, 사용자 추가했는지 확인 |
| 원생 목록이 안 보임 / 권한 오류 | `firestore.rules` 의 이메일이 로그인한 계정과 같은지 확인 |

- 학부모님께는 "등·하원 시 관장님 번호로 알림 문자가 발송됩니다"라고 미리 알리고 번호 사용 동의를 받아두세요.
- 서명키(`keep-private-20261026/jungdo-sign.jks`)는 이 앱 전용입니다. 잃어버리면 다음 APK를 덮어 설치할 수 없으니 PC·구글드라이브(비공개)에 보관하세요. 안드로이드 스튜디오로 직접 빌드할 때는 이 파일을 `app` 폴더에 넣으면 됩니다.

## ★ 관장님 폰 탭 구성 (2차 업데이트)

관장님 폰(문자 발송 폰) 화면 위쪽에 탭이 있어요:

| 탭 | 하는 일 |
|---|---|
| **오늘 출결** | 미등원 아이 목록(평소 오는 부 순서, 수업 시작 15분 지나면 빨간색) → **📞 어머님/아버님 바로 전화**, 💬 문자, 결석 처리. 사유 결석·등원 목록 |

| **명단·형제** | 수련생 현황 엑셀 + 연락처 파일 불러오기 → 미리보기 → 적용 |
| **문자·안내** | 등원/하원 문구, 날짜별 공통·부별 안내 |
| **상태·기록** | 문자 서버 켜기, 권한 체크, 문자 발송 기록 |
| **설정** | 부 시간표, 문자 받는 번호(대표/전체), 통화 후 창, 휴관일 추가, 테스트 문자 |

### 명단 정리 (매달 또는 수시로)
1. [명단·형제] → **① 현황 엑셀 선택** → '2026년 최신 정도 수련생현황.xlsx'
   - 학년 머리글(유치부, 1학년 … 중학생) 아래 이름 = 재원생
   - **회색 칸 = 시범단**, '휴관 / 휴관사유' 표 = 휴관, '형제명단' 표(번호 아래 세로로 적힌 이름끼리) = 형제
2. **② 연락처 파일 선택** → 출결 프로그램에서 내보낸 `contact_날짜.xls` (학부모 번호·**출결번호**·학교 그대로), 원하면 한 번 더 눌러 휴대폰 연락처 `.vcf`도 (아버님 번호 등 추가)
3. 미리보기 확인 → **이대로 적용하기**
   - 현황표에 **없는 아이 = 이번 달부터 퇴관**: 출석체크·미등원·출석부·문자에서 빠지고, **지난 달 출석부엔 그대로 남아요**
   - 다시 현황표에 올라오면 자동 복관
   - 형제는 학부모 번호가 똑같이 합쳐져요 (형제 모두 같은 어머님 번호)
4. 실시간 정리: 원생 이름 눌러서 상태를 **퇴관/휴관**으로 바꾸면 바로 반영
5. 옛날 `.xls`(엑셀 97-2003) 현황표는 엑셀에서 **다른 이름으로 저장 → .xlsx** 후 사용 (출결 프로그램 contact .xls 는 그대로 됨)

> 동명이인 원생은 번호를 자동으로 연결하지 않아요 → 미리보기의 ⚠️ 목록을 보고 이름 눌러 직접 입력.
> 출결 명단에만 있고 현황표에 없는 아이는 제외돼요.

### 출석 단말기: 출결번호로 출석
- 오른쪽 아래 **🔢 출결번호로 출석** → 4자리 입력 → 바로 등원/하원
- 형제가 같은 번호면 **"누구예요?"** 에서 이름 선택
- 이름 눌러 출석할 때도 **형제도 같이 왔나요?** 에서 형제를 같이 체크 가능

### 결석 사유 (부모님 연락)
- [오늘 출결] → **📝 부모님 연락 입력**: 아이 선택(형제 자동 표시) → 날짜(오늘/내일/기간) → 사유(빠른 버튼 또는 직접) → 저장
- 저장하면 미등원 목록에서 빠지고, 출석부에 빨간 **결** + 비고·'결석사유' 시트에 사유가 나와요. 퇴관 위험도 계산에서도 빠져요.

### 통화 끝나면 사유 입력 창 자동
- **앱에서 📞 누른 전화**: 통화가 끝나면 그 아이(같이 안 온 형제도 선택된 상태) 사유 입력 창이 바로 떠요 → 사유만 누르고 저장
- **일반 전화**(걸거나 받은 전화): 통화가 끝날 때 번호가 학부모 번호면 해당 아이(형제 포함) 창이 떠요. 모르는 번호는 안 떠요. ([설정]에서 끌 수 있음)
- 통화가 연결 안 됐으면 **다시 걸기** 버튼이 같이 나와요
- 다른 앱을 쓰고 있어도 동작 (문자 서버가 뒤에서 항상 돌고 있어서)
- 필요한 권한 ([상태·기록] 탭 준비 상태에서 버튼으로 허용):
  - 전화 걸기·통화 감지 (전화, 통화 기록)
  - **다른 앱 위에 표시** — 이게 없으면 창 대신 알림이 와요(누르면 창)
- 통화 기록 권한이 회색으로 막혀 있으면: 설정 → 애플리케이션 → 정도 출결 → ⋮ → **제한된 설정 허용** 후 다시

### 퇴관 위험도 계산
- 점수 = 평소보다 덜 나오는 정도(최대 50) + 마지막 출석 후 빠진 수업일(최대 40) + 최근 출석률 20% 미만(10)
- 60점↑ 위험, 30점↑ 주의. 주 2~3회 오는 아이도 '자기 평소' 기준이라 억울하게 높게 안 나와요
- 출석 기록이 2주 이상 쌓여야 정확해요 (처음엔 '기록 부족')

### 학년 자동 진급 (나이 기준) — v11
- 원생 문서에 `age`(나이), `ageYear`(그 나이를 정한 해)를 저장. 올해 나이 = `age + (올해 - ageYear)` → **해가 바뀌면 자동으로 1살씩 올라감**.
- 나이 → 학년: 7세 이하 유치부 / 8~13세 1~6학년 / 14~16세 중1~중3 / 17~19세 고1~고3 / 20세 이상 성인 (`data/GradeCalc.kt`).
- 화면에 보이는 학년(`Student.grade`)은 불러올 때 나이로 계산해 넣음. 저장된 `grade` 글자는 참고용.
- 나이가 없는 원생(유치부·중학생·고등학생 등)은 글자 그대로 두고 자동 진급 안 됨 → 원생 수정에서 나이 입력. [명단·형제] 탭에 안내 표시.
- 옛 데이터: 정확한 학년(`2학년`)이 적힌 원생은 첫 실행 때 올해 나이로 자동 저장(`Repo.migrateAges`).
- 월간 출석부는 그 달 기준 학년(`Student.gradeAt(month)`)으로 묶음.

### 계급·경험치 — v13
- `data/Rank.kt`: 레벨 1~866, 경험치 18,000이 최고. 등원 +10 / 하원 +10 (하루 한 번씩) + 연속 출석 보너스(연속 2일째부터 +2씩, 최대 +20). 레벨 곡선은 `MAX_EXP * ((레벨-1)/865)^1.3`.
- 원생 문서 필드: `exp`, `streak`, `streakDay`, `inDay`, `outDay`. 경험치 칸은 `studentData`(명단 저장)에 넣지 않고 `Repo.awardExp` / `Repo.setExp` 로만 씀 → 명단 불러오기가 덮어쓰지 않음.
- 키오스크 `attend()` 에서 `Repo.awardExp` 호출, 완료 화면에 계급 그림(`ui/RankUi.kt`, `assets/rank/001~866.png`)과 경험치 표시.
- 다른 앱(태권도 카드·attack·index3 RPG)에서 같은 Firebase `students/{id}` 의 `exp`, `streak` 를 읽으면 계급을 이어서 쓸 수 있음. 레벨 계산식은 `Rank.levelOf` 와 같게 맞출 것.

### 계급 표시·레벨 업 연출 — v14
- 계급 그림은 키오스크의 이름 왼쪽에 항상 표시: 등원/하원 선택 팝업, "누구예요?" 버튼, 완료 화면 (`kiosk/KioskScreen.kt`).
- `ui/RankUi.kt` 의 `AwardRow` 가 완료 화면의 한 줄(그림·이름·Lv·경험치·막대)과 레벨 업 연출을 담당: 막대 끝까지 → 새 그림 튀어나옴(spring) → "레벨 업!" 깜빡임 → 막대 재충전.
- 완료 화면은 3.5초 후 자동으로 닫힘. `assets/rank/721.png` 는 1254px → 256px 로 줄임.
